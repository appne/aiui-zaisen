# aiui-zaisen

Keihan Main Line train-position agent for Rokid Glasses.

Fetches the official Keihan train-position JSON
(https://www.keihan.co.jp/zaisen-up/trainPositionList.json) and renders
train positions between stations on the Keihan Main Line
(Yodoyabashi KH01 - Demachiyanagi KH42) in a glasses-native list.
Voice launch name should stay short, e.g. "zaisen".
Personal use only; do not submit for store review.
